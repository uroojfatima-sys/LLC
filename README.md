# AWAY FROM WORK, LLC ✦

### A calmer digital experience, translated from Figma to code.

**Away From Work, LLC** is a pixel-perfect frontend recreation of a modern digital experience focused on creating a safe, private, and supportive environment for employees.

The project was translated from a Figma design into a functional responsive website using **HTML, Tailwind CSS, Vanilla JavaScript, and Vite**.

The goal was not simply to reproduce the layout.

It was to recreate the **feeling of the design** — the typography, spacing, colors, visual rhythm, interactions, and overall sense of calm and clarity.

---

# ✦ The Idea

Away From Work is built around a simple concept:

> **People need space to step away, reset, and find clarity.**

The website communicates that idea through a soft but confident visual language.

The interface combines:

* Deep purple tones
* Soft lavender backgrounds
* Large editorial typography
* Rounded UI elements
* Generous whitespace
* Gradient transitions
* Human-centered messaging
* Calm visual movement

The result is an interface that feels intentional, modern, and approachable.

# 📐 PIXEL-PERFECT APPROACH

Pixel-perfect recreation means paying attention to the details that are easy to overlook.

For this project, particular attention was given to:

### Spacing

Maintaining the visual rhythm between sections and components.

### Typography

Matching font sizes, line heights, weights, and hierarchy.

### Colors

Preserving the original purple and lavender palette.

### Gradients

Recreating the transition between light and dark sections without losing the original visual character.

### Cards

Maintaining their dimensions, borders, radius, shadows, and interaction states.

### Responsive Layout

Adapting the design without destroying the original proportions.
